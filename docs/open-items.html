Read this before previewing locally

Every page now pulls its header and footer in with a small script (fetch()), so the same markup isn't copy-pasted into 14 files. That only works when the site is served over http — Live Server, or GitHub Pages once it's live. Opening a page by double-clicking it (file://) will show it with no header or footer. Always preview through Live Server from here on.
