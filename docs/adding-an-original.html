MollyArtSite — how-to

Adding an original artwork to the shop

Every original artwork has its own page, like original-morning-light.html. To add one, copy an existing page and change the parts marked EDIT. No code knowledge needed. You only change words, numbers and file names.

1. Make the PayPal button

  1. In PayPal, create a new cart product for the artwork (title, price, description). Turn on shipping address collection and set the quantity to 1. See When a sale comes in for why.
  2. On the Add to Cart tab, click Copy Code. Keep it handy for step 5.

Each artwork needs its own PayPal product. The code has an ID in it, such as RDM8UR7HDALYG, and that ID is what tells PayPal which painting is being bought.

2. Add the photo

Put the photo in the images folder. Use a simple name with no spaces, such as quiet-harbor.jpg.

3. Copy a page

  1. Copy original-morning-light.html. It's the one with a working PayPal button, so it's the best example.
  2. Rename the copy original- + the artwork name, all lowercase with dashes instead of spaces. For example: original-quiet-harbor.html. Keep the original- at the start. It's how the menu knows to underline Shop on this page.

4. Change each EDIT spot

Open the new page and search for EDIT. Each one sits just above the thing to change:

  • Title — appears twice: in <title> near the top (the browser tab) and in <h1>.
  • Main photo — swap the placeholder line for the <img> line shown in the comment, with your photo's file name and a short description.
  • Price, medium and size, details for buyers.
  • Extra photos — optional. You can leave these as they are.

5. Paste the PayPal code

Find these two lines:

<!-- PayPal Add to Cart START -->
...
<!-- PayPal Add to Cart END -->

Delete everything between them and paste the code from step 1 in its place. Keep the START and END lines themselves.

Double-check this one. If the copied page still has Morning Light's PayPal code, the new page will sell Morning Light. The ID in the pasted code should match the one PayPal showed you for this artwork.

Leave the View Cart button below it alone. It's the same on every page.

6. Add a card to the Originals page

  1. Open shop-originals.html and find the cards. Each one is an <a href="original-…"> … </a> block.
  2. Copy one whole block and paste it right after the last one.
  3. Change the href to your new page's file name, then the title and price.

7. Check it

  1. Open the Originals page with Live Server and click the new card. It should open the new page.
  2. Click Add to Cart, then the cart button. The cart should list the new artwork's name and price.

When a sale comes in

The website never sees a sale. Checkout happens on PayPal, so PayPal is what tells you someone bought something.

How you'll hear about it

  • Email: PayPal emails the address on your PayPal account for every payment. The email shows what was bought, the amount, and the buyer's name and shipping address.
  • PayPal app: install it on your phone and you'll also get a notification for each sale.
  • Activity page: every order is listed in PayPal under Activity, with the full details.
  • Choosing what you get: PayPal's account settings have a notifications section where you can turn emails and app alerts on or off. The exact menu names may differ a little from these.

Check these before real sales start

  • Shipping address: when making each PayPal product, make sure it's set to collect a shipping address. Without it you won't know where to send the artwork.
  • Only one can be sold: look for a stock or inventory option when making the product and set it to 1. PayPal then shows "sold out" to anyone else instead of letting a second person buy the same painting.
  • Test mode sends no real emails: while the site is still on PayPal's test setup (sandbox), no sale emails reach your real inbox. They appear in PayPal's developer dashboard instead. Real emails start once the site is switched to live PayPal.

After a sale

  1. Pack and ship the artwork to the address in the PayPal email.
  2. In PayPal's Activity page, mark the order as shipped and add the tracking number. The buyer gets notified.
  3. Remove the artwork's card from shop-originals.html (delete the whole <a> … </a> block).
  4. If you didn't set the quantity to 1, turn off or delete the product in PayPal so no one can buy it twice.

The artwork's page itself can stay. Without its card, nobody can reach it from the shop.

Same steps work for prints once those pages are split up the same way.
